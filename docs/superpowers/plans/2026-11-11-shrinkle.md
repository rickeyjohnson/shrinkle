# SHRINKLE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, inline — deadline 5:50 pm). Steps use checkbox (`- [ ]`) syntax.

**Goal:** One-file browser game. 7 rounds, each with a new category and 20 s per word. Every word must be shorter than the last. Daily seed, 5,000+ generated categories, low-poly 3D zoom from galaxy to atom.

**Architecture:** One `shrinkle.html`: inline data strings → category generator → seeded daily ladder → round state machine → DOM HUD (.io style) over a Three.js canvas (r128 from cdnjs, optional).

**Tech Stack:** Vanilla JS, Three.js r128 UMD (cdnjs), Google Fonts (Baloo 2), WebAudio blips.

**Spec:** `SHRINKLE-NOTES.md`

## Global Constraints
- Single .html file; it plays (minus 3D) even if the CDN fails.
- 7 rounds × 20 s; every run ends on the results/win screen in under 5 min.
- `points = len × (10 + ceil(secondsLeft))`, ×1.5 if deep cut; time-out or skip = 0 and the cap stays the same.
- Zoom levels in order: Milky Way, Solar System, Earth, Continent, Country, Human, Atom.
- Same date → same ladder for everyone.

## Review Focus
1. Typed word valid in the base list but not in this category → clear "not in this category" message, no crash.
2. Aliases with spaces/punctuation ("New York", "Côte d'Ivoire") → normalized to letters only.
3. Cap shrinks below every answer in a later category → auto 0, run continues to the results screen.
4. Keyboard focus lost (click outside) → typing still works (window-level keydown).
5. Three.js fails to load → game still playable, gradient background.
